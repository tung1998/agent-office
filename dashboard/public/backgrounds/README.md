# J2TEAM backgrounds

Public presets supplied and approved for inclusion by the repository owner. These are optional choices; existing accounts keep their current theme.

Sources: [13-image folder](https://drive.google.com/drive/folders/10o5iq5xbUBjM2K5fW-FqtFD1jH55ke1q), [FJ2 - DG.MP4](https://drive.google.com/file/d/1R7EttiXm-j8k0yAse-ddigzzdJdii78h/view), [J2teaM.bmp](https://drive.google.com/file/d/0B31mZpan9psMQ0tncnREZUhrZkk/view?resourcekey=0-77nBlSGk5JgFPKeXHKLfYQ).

The BMP is a static 2560×1440 bitmap, not an animated GIF. The video source is 2560×1440 H.264 at 24000/1001 fps, about 119.47 seconds.

Images were resized with ImageMagick Lanczos to fit within 3840×2160 without cropping or changing aspect ratio, mildly sharpened (`-unsharp 0x0.7+0.45+0.02`) and encoded as WebP quality 88. Float was already 3840×2160. Resampling preserves the design; it does not reconstruct original missing detail. Source files were preserved. Separate PNG renders and a 4K MP4 derivative were uploaded to the supplied Drive folder, with `4K enhanced` in the filenames.

The bundled MP4 keeps the source 1440p resolution and frame rate, uses H.264/yuv420p with fast-start, mild sharpening and no audio. The video is only requested when selected; the picker uses a still poster. Higher-resolution archive renders are not committed here.
