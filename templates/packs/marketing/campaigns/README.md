# Chiến dịch

Mỗi chiến dịch một thư mục `<YYYY-MM>-<tên>/`:

- `plan.md`: kế hoạch (quy trình `#campaign-plan`, skill `campaign`).
- `<kênh>-<n>.md`: từng nội dung, cuối file có checklist đăng (skill `assets`).
- `review-<YYYY-MM-DD>.md`: đánh giá từ số liệu (quy trình `#campaign-review`).
- Số liệu chủ xuất ra (CSV) đặt luôn trong thư mục này.
