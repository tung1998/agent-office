# Kho câu trả lời

Mỗi file một câu hỏi khách hay hỏi, viết theo skill `knowledge-base`. Thêm các file này làm **phương án** (Khách hàng → Phương án, loại file) để `support_kb_search` tìm được; office đồng bộ lại mỗi giờ khi file đổi.

Quy trình `#weekly-faq` thêm và sửa file ở đây; mọi câu trả lời phải lấy từ `docs/policies.md`.
