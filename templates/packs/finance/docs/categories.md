# Danh mục

Danh mục của bạn, Ghi sổ dùng đúng tên ở đây. Sửa thoải mái: gộp, đổi tên, thêm danh mục con.

| Danh mục | Danh mục con (ví dụ) |
|---|---|
| Ăn uống | Đi chợ, ăn ngoài, cà phê |
| Đi lại | Xăng, gửi xe, Grab, vé tàu xe |
| Nhà cửa và hóa đơn | Tiền nhà, điện, nước, internet, điện thoại |
| Mua sắm | Quần áo, đồ gia dụng, điện tử |
| Sức khỏe | Thuốc, khám, bảo hiểm |
| Giáo dục | Học phí, sách, khóa học |
| Giải trí | Phim, du lịch, đăng ký dịch vụ |
| Gia đình và quà | Biếu, quà, hiếu hỉ |
| Phí và lãi | Phí ngân hàng, lãi thẻ, lãi vay |
| Thu nhập | Lương, thưởng, thu nhập phụ, hoàn tiền |
| Tiết kiệm và đầu tư | Chuyển vào tiết kiệm, quỹ, cổ phiếu |
| Khác | |
