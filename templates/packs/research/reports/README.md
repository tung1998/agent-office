# Báo cáo

Mỗi câu hỏi một file `<YYYY-MM-DD>-<slug>.md` (skill `synthesis`): câu trả lời trước, độ tin cậy, các phát hiện có trích dẫn [1], [2]…, điều chưa biết, điều làm thay đổi kết luận, danh sách nguồn ở cuối.

- Quét thị trường: `<YYYY-MM-DD>-scan-<slug>.md`.
- Bản tin tuần: `<YYYY>-W<tuần>-digest.md`.
