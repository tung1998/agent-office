# Spec

Mỗi tính năng lớn một file `<YYYY-MM-DD>-<slug>.md`, viết theo skill `spec` (quy trình `#feature-spec`): vấn đề, màn hình và luồng, tiêu chí chấp nhận theo nền tảng, quyền và quyền riêng tư, ngoài phạm vi, dữ liệu và API, file, rủi ro, câu hỏi mở. Bạn duyệt tiêu chí chấp nhận trước khi làm.
